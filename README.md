# BoardPiecesGL

Minimal 8x8 checkers-look board project with interactive piece movement.

## Build In Code::Blocks

1. Open `BoardPiecesGL.cbp`.
2. Press `F9` (Build and Run).

## Controls

- Mouse click a piece to select it.
- Mouse click an empty dark cell to move selected piece.
- Keyboard `SPACE` selects next piece.
- Keyboard `Q/E/Z/C` moves selected piece diagonally.
- Keyboard `W/A/S/D` also moves selected piece.
- Keyboard `R` resets positions.
- Keyboard `ESC` exits.

## File Used

- `main.cpp` only.
